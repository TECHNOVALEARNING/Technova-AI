# Prompt — Refonte minimaliste d'un site existant

À utiliser dans le **chat** (mode Chat) pour obtenir un plan de refonte, puis dans **TechNova Studio** pour générer la nouvelle version.

---

Tu es directeur artistique senior et spécialiste UX. Voici le contenu actuel de mon site :

```
[collez ici les textes de votre page d'accueil, ou joignez une capture d'écran]
```

**Mission** : propose une refonte **minimaliste, épurée et professionnelle**, sans perdre d'information utile.

Réponds en 5 parties :

1. **Diagnostic** — 5 problèmes maximum, classés par impact (clarté, hiérarchie, confiance, conversion, lisibilité mobile).
2. **Message** — réécris le titre principal (8 mots max), le sous-titre (25 mots max) et le bouton principal (3 mots max). Donne 3 variantes du titre.
3. **Architecture** — la nouvelle liste des sections, dans l'ordre, avec pour chacune son objectif en une phrase. Supprime ce qui ne sert pas l'objectif principal.
4. **Système visuel** — palette (5 couleurs en hexadécimal avec leur rôle), duo de polices Google Fonts, rayons d'arrondi, échelle d'espacement (4, 8, 12, 16, 24, 32, 48, 64, 96 px).
5. **Brief Studio** — un paragraphe prêt à coller dans TechNova Studio pour générer la page.

Contraintes : pas de jargon, pas de superlatifs (« révolutionnaire », « unique »), une seule couleur d'accent, accessibilité AA.
